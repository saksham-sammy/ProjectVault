# 🚀 ProjectVault

ProjectVault is an executive developer project management dashboard and launch hub built to orchestrate and monitor multi-repo development workflows.

---

## ✨ Key Features

- One-click launch hub (VS Code, Terminal, Running App, GitHub)
- Direct ZIP export / download feature for all managed projects
- Lifecycle, priority, and completion percentage tracking
- Milestones roadmap and developer engineering journal with SQLite persistence

```bash
# Clone the repository
```
